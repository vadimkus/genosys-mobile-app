## 🚀 Quick Start

### On iPhone 15 Pro Max:

1. Install app from TestFlight
2. Navigate to each screen
3. Take screenshot: **Side Button + Volume Up**
4. AirDrop photos to Mac
5. Rename files (01-splash-or-home.png, 02-shop-products.png, etc.)
6. Move to `app-store-screenshots/6.7-inch/` folder

### On Simulator:

```bash
# Start iPhone 15 Pro Max simulator
open -a Simulator

# Take screenshot
Press: Command + S

# Screenshots save to Desktop
```

## ⚠️ Common Mistakes to Avoid

- ❌ Wrong dimensions
- ❌ Test data visible (email: test@example.com)
- ❌ Low battery indicator
- ❌ Placeholder images
- ❌ Developer/debug info
- ❌ Wrong time on status bar
- ❌ Personal information
