## 📱 Upload Instructions

### Quick Upload (5 minutes)

1. **Open Finder**
   ```bash
   open app-store-screenshots/appstore-ready/
   ```

2. **Go to App Store Connect**
   - URL: https://appstoreconnect.apple.com
   - Sign in → My Apps → Genosys Mobile App
   - Click "App Store" tab

3. **Upload Screenshots**
   - Scroll to "App Previews and Screenshots"
   - Select "6.7" Display"
   - Click "+" and select all 6 files from `appstore-ready/`
   - Drag to reorder (already named in correct order)

4. **Save**
   - Click "Save" (top right)

**Done!** ✅

## 🔄 Future Updates

### Re-capturing Screenshots

When you update the app or want new screenshots:

```bash
# 1. Start iOS simulator
npm run ios

# 2. Log in and navigate to desired screens
# (wait for app to fully load)

# 3. Run automated capture
npm run screenshots

# 4. Convert to App Store format
bash scripts/convert-screenshots-appstore.sh

# 5. Upload new screenshots to App Store Connect
open app-store-screenshots/appstore-ready/
```

### Localization

To create Arabic or Russian screenshots:
1. Change simulator language
2. Restart app
3. Run `npm run screenshots`
4. Upload to respective localizations
