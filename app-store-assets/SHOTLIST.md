## Screenshot shot list (recommended)

Use the same filenames across each device folder so uploads are consistent.

### Suggested filenames (EN locale)

Core flow:
- `01-home.png` — Home screen (hero + categories + products)
- `02-shop.png` — Shop / product grid + search
- `03-product.png` — Product detail (benefits/details visible)
- `04-bag.png` — Bag (items + promo progress)
- `05-checkout.png` — Checkout (delivery + payment + summary)
- `06-orders.png` — Orders list (pending + pay now)
- `07-order-details.png` — Order details (expanded summary)
- `08-account.png` — Account page (language + quick actions)

Support / trust (optional but helpful):
- `09-help.png` — Help & Support page (WhatsApp + FAQ)
- `10-privacy.png` — Privacy Policy screen (in-app)

### Capture per device set

Put the same set into each folder:

- `screenshots/iphone-6.7/`
- `screenshots/iphone-6.5/`
- `screenshots/iphone-5.5/`
- `screenshots/ipad-12.9/`
- `screenshots/ipad-11/`

### Optional: RU + AR localized screenshot sets

If you want localized App Store pages later, repeat the same shot list in RU/AR
and suffix filenames, e.g.:

- `01-home-ru.png`, `01-home-ar.png`
